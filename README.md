# NAS115Sync — NAS ⇄ 115 網盤比對、同步與檔案管理（Windows 11）

在 Win11 電腦上執行，把 NAS 上所有資料夾與 115 網盤比對（檔名 + MD5 + SHA-1 + 上次同步基準），
需要判斷的地方一律交給**本人核對**，其餘自動處理：

- **上傳優先觸發 115 秒傳**、大檔**斷點續傳**、上傳後讀回 SHA-1 **驗證**
- **下載前先找 NAS 上相同內容的檔案直接複製**（下載版的秒傳），下載可**續傳**並驗證 SHA-1
- 每個路徑對應可選 **上傳（NAS→115）／下載（115→NAS）／雙向同步**
- 像 **OneDrive 桌面同步**一樣**雙向即時連動**：NAS 的變動即時上傳；在 **115 電腦版／App** 上的新增、修改、改名、搬移、刪除約 30 秒內同步到 NAS
- **不需要 open.115.com 開發者 AppID**：登入方式與 115 電腦版相同（115 App 掃碼），看到的是同一個網盤
- 遊戲存檔（savedata）像 **Steam 雲存檔**：遊戲寫完存檔後自動上傳並刪除 115 舊版；雙向時也會把別台電腦的新存檔拉回來
- 內建 **Air Explorer 式雙窗格瀏覽器**（NAS ⇄ 115）、**傳輸佇列**（暫停／取消／限速）、**重複檔案分析**、**多個 115 帳號**

> ⚠️ 本程式使用與 **115 電腦版／網頁版相同的介面**（不是 115 公開給開發者的 API，115 改版時可能需要更新程式）。
> 開發環境無法連線 115，因此**沒有在真實 115 帳號上實測過**；通訊格式已與公開的參考實作逐位元比對，
> 自動測試用「模擬 115」與 Windows 實機（GitHub Actions）執行。
> **請先登入後按「115 連線測試」**（實際測試上傳、秒傳、下載、改名、刪除，只動一個測試資料夾），
> 再以少量資料夾實際試用，確認無誤後再擴大範圍。

## 與 Air Explorer 的比較

提供的 `AirExplorer-Installer.exe` 只是 411 KB 的 Inno Setup 下載器，裡面沒有 Air Explorer 的程式碼；
而且 Air Explorer 是商業軟體，本專案**沒有反編譯或複製它的程式碼**，而是依其公開的功能自行實作，
並把它已知與可能的缺點改成實際功能。

### Air Explorer 的功能 → 本程式

| Air Explorer | NAS115Sync |
|---|---|
| 雙窗格檔案總管、拖放傳輸 | 「瀏覽」分頁：左 NAS、右 115，上傳／下載／新資料夾／改名／刪除／移動／在 115 瀏覽器開啟 |
| 搜尋雲端檔案 | 「瀏覽」分頁的 115 搜尋（可限定資料夾）、指令 `search` |
| 多帳號（Pro） | 多個 115 帳號，每個路徑對應可指定帳號，登入資訊分開以 DPAPI 加密保存 |
| 同步模式：鏡像、更新鏡像、雙向 | 每個對應可選：上傳、下載、雙向；刪除處理可選「本人核對／自動同步刪除（可復原）／不處理」 |
| 同步預覽 | 「① 掃描比對」只比對不傳輸；可**匯出 CSV 比對報告** |
| 排程工作（Pro） | 「設定 → 排程」：指定星期與時間自動完整比對／同步 |
| 傳輸佇列、暫停／繼續 | 「傳輸」分頁：每個檔案的進度、速度、狀態；全部暫停／繼續、取消單一傳輸 |
| 頻寬限制（Pro） | 上傳／下載各自限速，**即時生效** |
| 篩選（副檔名等） | 每個對應：只含／排除（檔名或路徑規則）、檔案大小範圍、略過隱藏／系統檔 |
| 指令列（Pro） | `run_cli.bat`：scan / sync / watch / upload / download / ls / search / dupes / schedule … |
| 代理伺服器 | 設定「代理伺服器」 |

### Air Explorer 的缺點 → 本程式的做法

| 缺點 | 改進 |
|---|---|
| 1. 無法即時同步（只能手動或排程） | 即時監看 NAS 變動（OneDrive 式），檔案寫完穩定後才處理；網路磁碟漏事件時由定期完整比對補抓；NAS 斷線後自動重新監看 |
| 2. 無法用雲端雜湊比對（只看日期／大小） | NAS 端一次讀取同時算 MD5、SHA-1，與 115 的 SHA-1 比對；再加上「上次同步基準」三方比對，能分辨是哪一邊改的，不會因修改時間誤判 |
| 3. 沒有 115 秒傳 | 每次上傳都先送整檔 SHA-1 + 前 128KB SHA-1 + 二次驗證；批次同步先對全部檔案嘗試秒傳，再實際上傳其餘檔案 |
| 大檔中斷要從頭重傳 | 分片上傳資訊存在資料庫，中斷（甚至重開程式）後只補傳缺少的分片；下載以 Range 續傳 |
| 雙向同步衝突處理粗糙 | 兩邊都改過一律交給本人核對：以 NAS 版或 115 版覆蓋、或保留兩者（舊版改名） |
| 鏡像模式誤刪資料 | 預設刪除交給本人核對；大量刪除（疑似 NAS／115 離線）一律暫停；NAS 離線絕不判定為刪除；115 刪除進回收站；NAS 被覆蓋／刪除的檔案先移到可復原資料夾（預設保留 30 天） |
| 傳輸後不驗證 | 實際上傳後向 115 讀回 SHA-1 驗證，不符時不刪除舊版並列入待核對；下載完成驗證 SHA-1，不符自動重新下載 |
| 下載浪費頻寬 | 下載前先找 NAS 上相同 SHA-1 的檔案直接複製 |
| 沒有版本保留 | 上傳新版時 115 舊版可保留 N 份（一般檔案與遊戲存檔可分別設定） |
| 不會找重複檔案 | 「重複檔案」分頁依 SHA-1 列出 NAS 與 115 上重複的檔案與浪費空間，可刪除 115 多餘副本 |
| 搬移／改名會重新上傳 | NAS 上搬移或改名已同步的檔案／資料夾，直接在 115 搬移或改名 |
| 遊戲存檔沒有專門處理 | 存檔群組本人核可後像 Steam 雲存檔：靜置＋遊戲結束才上傳；雙向時定期拉回別台電腦的新存檔（遊戲執行中不覆蓋） |

### 刻意沒有加入的 Air Explorer 功能

- **其他雲端（Google Drive、OneDrive、Dropbox…）**：本工具專注 NAS ⇄ 115。程式以 `CloudClient` 介面隔開，日後可另外實作。
- **上傳前加密**：加密後內容每次都不同，會讓 115 秒傳與 SHA-1 比對全部失效，與本工具的核心需求衝突。
- **分享連結、縮圖／影音預覽**：與同步無關，可用「在 115 瀏覽器開啟」或 115 電腦版處理。

| 需求 | 本程式做法 |

| NAS 所有資料夾與 115 比對 | 「自動建議」列出 NAS 根目錄下所有資料夾，依名稱配對 115 資料夾 |
| 以檔名、MD5、SHA-1 比對 | 每個 NAS 檔案一次讀取同時算 MD5、SHA-1（結果快取，不重算）；115 端使用其提供的 SHA-1 |
| **比對路徑要本人核對** | 每組 NAS⇄115 對應都必須在「核對確認」視窗看過兩邊內容、勾選「我已本人核對」才會同步；路徑或帳號變更後需重新核對 |
| **相同檔名或 MD5 或 SHA-1 要本人核對** | 同檔名不同內容、相同 MD5/SHA-1 出現在別處、同檔名出現在別的資料夾，都列入「待核對」 |
| **savedata 遊戲存檔要本人核對** | 偵測到存檔資料夾時先列入「待核對」，本人核可後才啟用自動同步 |
| 存檔像 Steam 雲存檔 | 核可後：存檔變動 → 靜置（且遊戲程序結束）→ 上傳新版 → **刪除 115 舊版**（可改為保留 N 份） |
| 用 115 上傳、盡可能觸發秒傳 | 與 115 電腦版相同的上傳介面與秒傳判斷（見下節） |
| 像 OneDrive 一樣時時同步 | NAS → 115 即時監看；115 → NAS 讀取 115 操作紀錄（約 30 秒）；雙向模式 + 定期完整比對 + 排程 |
| 不用 open.115.com，用本機 115 網盤 | 登入與檔案介面與 115 電腦版相同，與 115 電腦版顯示同一個網盤、互相即時連動 |

### 與 115 電腦版（115 網盤程式）的連動

115 電腦版本身沒有可供其他程式呼叫的同步介面，舊的「115 同步盤」也已停止，用程式去點 115 電腦版的畫面既不穩定也無法大量處理。
因此本程式**直接使用 115 電腦版／網頁版背後的同一套介面**：

- **登入**：用 115 App 掃 QR 碼，與 115 電腦版相同；不需要申請 open.115.com 開發者 AppID。
  115 每種「登入裝置」只允許一個連線，本程式預設使用「支付寶小程序」欄位，**不會把你電腦上的 115 電腦版或手機 App 擠下線**。
- **同一個網盤**：本程式上傳、改名、刪除的檔案，115 電腦版立刻看得到；
  你在 115 電腦版（或 App、網頁）上新增、修改、改名、搬移、刪除，本程式讀取 115 的「操作紀錄」，約 30 秒內同步到 NAS
  （改名、搬移直接在 NAS 上改名／搬移，不重新下載）。
- **秒傳**：與 115 電腦版相同的判斷——整檔 SHA-1、必要時依 `sign_check` 計算指定區段 SHA-1 做二次驗證；
  115 上已有相同內容就秒傳完成，否則實際上傳（大檔分片、可續傳）。
- 需要人工確認時，程式提供「**在 115 瀏覽器開啟**」按鈕。

## 安裝

### 方式一：直接使用 exe（建議）

不需要安裝 Python。兩個檔案都是單一檔案程式：

| 檔案 | 用途 |
|---|---|
| `NAS115Sync.exe` | 圖形介面（雙擊開啟） |
| `NAS115Sync-CLI.exe` | 指令列（排程、批次、Windows 工作排程器用），指令與下方「指令列」一節相同 |

1. 取得 exe：
   - GitHub → 此專案 → **Actions** → 最新一次「Windows build & test」→ 下方 **Artifacts** 下載 `NAS115Sync-windows-exe`（需登入 GitHub，保留 90 天）；或
   - 自行打包：安裝 Python 後雙擊 **`build_exe.bat`**，會產生 `dist\NAS115Sync.exe`、`dist\NAS115Sync-CLI.exe` 並自動做一次自我測試。
2. 把兩個 exe 放到固定的資料夾（例如 `C:\NAS115Sync\`，不要放在「下載」或暫存資料夾，因為開機自動啟動會記住這個位置）。
3. 第一次開啟若出現 **「Windows 已保護您的電腦」**（SmartScreen，因為程式沒有付費數位簽章）：按 **「其他資訊」→「仍要執行」**。
   防毒軟體若誤報（PyInstaller 打包的程式偶爾會被誤判），請將資料夾加入例外。
4. 先試用示範模式：在資料夾空白處按 Shift + 右鍵 →「在終端機中開啟」，輸入 `.\NAS115Sync.exe --demo`。

**確認在這台電腦上能正常運作**：執行
`.\NAS115Sync-CLI.exe --self-test "$env:TEMP\nas115sync-selftest"`
會以模擬 115（不需帳號、不影響正式設定）測試所有元件：元件載入、QR 碼、登入資訊加密、MD5/SHA-1 與超長路徑、
雙向同步、遊戲存檔、**即時監看**、手動上傳下載與資源回收筒、程序偵測，
並**實際開啟主視窗、依序按下每個分頁的每個按鈕**（對話框自動回答，全程不可出現任何錯誤）。
畫面顯示「自我測試通過」即可放心使用；失敗時把 `selftest_report.json` 提供給開發者。
（測試會把兩個暫存的測試項目「刪除我.txt」「改名後」放進資源回收筒，可直接清除。）

每次推送到 GitHub 時，Windows 實機都會自動：跑全部測試 → 打包兩個 exe → 執行打包後 exe 的自我測試（按遍所有按鈕並截圖每個分頁）→ 測試指令列 exe，全部通過才會產出 exe。

### 方式二：用 Python 原始碼執行

1. 安裝 [Python 3.10 以上](https://www.python.org/downloads/)（安裝時勾選 **Add python.exe to PATH**）
2. 雙擊 **`install.bat`**（建立虛擬環境並安裝套件）
3. 雙擊 **`run_demo.bat`** 用示範模式試用；正式使用雙擊 **`run_gui.bat`**；指令列用 `run_cli.bat`

### 其他

- 同一個 Windows 帳號只會開啟一個 NAS115Sync（再開會提示「已在執行中」），避免兩份即時同步同時寫入。
- 「設定」勾選「Windows 開機時自動啟動」後，登入 Windows 就會在背景開始即時同步。

## 登入 115

「總覽」頁 → **115 App 掃碼登入**（可先在左側選擇帳號）：

1. 選擇「登入裝置欄位」。115 每種裝置只允許一個登入，**請選你沒有在用的那一種**，否則該裝置上的 115 會被登出。
   預設的「支付寶小程序」不會影響 115 電腦版（Windows）與手機 App；程式也刻意不提供 Windows 欄位。
2. 按「顯示 QR 碼」，用手機 115 App 掃描並確認。
3. 登入後按 **115 連線測試**：在 115 建立一個測試資料夾，實際測試上傳、秒傳、SHA-1 核對、下載、改名、讀取操作紀錄，最後整個刪除（進 115 回收站）。

按「＋」可新增其他 115 帳號，每個帳號分別登入；路徑對應可指定使用哪個帳號。
登入資訊以 Windows DPAPI 加密存放（只有目前的 Windows 使用者能解開；加密失敗時不保存，絕不以明文寫入）。
「登出」會刪除本機保存的登入資訊；也可以在 115 App 的「登入裝置管理」移除此裝置。

## 使用步驟

1. **路徑對應** → 「自動建議（NAS 所有資料夾）」或「新增…」。在對應中設定**同步方向**、刪除處理、帳號與篩選。
2. 選取每一筆對應 → **核對確認**：同時列出 NAS 與 115 兩邊第一層內容、兩邊同名項目、
   與其他對應重疊的警告，可開啟兩邊實際查看；勾選「我已本人核對」後才能確認。**未核對的對應不會被比對或同步。**
3. **總覽** → **① 掃描比對**（不會傳輸）→ 可「匯出比對報告（CSV）」用 Excel 逐項檢查。
4. **待核對** 頁逐項（或同類型多選）處理需要本人判斷的項目。
5. **總覽** → **② 執行同步**。
6. **總覽** → **▶ 開始即時同步**；「設定」可勾選開機自動啟動、設定排程。
7. 其他：**瀏覽** 分頁手動在任何 NAS 資料夾與 115 資料夾間傳輸、比較；**傳輸** 分頁管理佇列與限速；
   **重複檔案** 分頁找出重複內容。

## 比對規則（三方比對）

每個檔案同時看「NAS 現況」「115 現況」「上次同步完成時兩邊的 SHA-1（同步基準）」。

| 情況 | 上傳模式 | 下載模式 | 雙向模式 |
|---|---|---|---|
| 兩邊 SHA-1 相同 | 已同步，記錄基準 | 同左 | 同左 |
| 同路徑內容不同、無基準 | **待核對** | **待核對** | **待核對** |
| 只有 NAS 改過 | 上傳新版、處理 115 舊版 | **待核對**（NAS 被改了） | 上傳 |
| 只有 115 改過 | **待核對** | 下載新版（NAS 舊版可復原） | 下載 |
| 兩邊都改過 | **待核對** | **待核對** | **待核對** |
| NAS 新檔案 | 上傳（相同 MD5/SHA-1 或同檔名在別處 → **待核對**） | 只列出，不處理 | 同上傳模式 |
| 115 新檔案 | 只列出，不處理 | 下載（NAS 已有相同 SHA-1 → **待核對**，下載時直接從 NAS 複製） | 同下載模式 |
| NAS 刪除 | 依刪除設定（預設**待核對**） | **待核對**（可從 115 還原） | 依刪除設定 |
| 115 刪除 | **待核對**（可重新上傳） | 依刪除設定（NAS 檔移到可復原資料夾） | 依刪除設定 |
| 大量刪除（預設 ≥20 個且 ≥30%） | 一律暫停，**待核對** | 同左 | 同左 |
| 遊戲存檔群組第一次出現 | **待核對** | 同左 | 同左 |

> 115 只提供檔案的 SHA-1；MD5 由本程式在 NAS 端計算，並記錄每個已同步檔案的 MD5，用來比對 NAS 各處及已同步檔案的 MD5。

### 安全設計

- 只有本人核對過的路徑對應才會同步；路徑或帳號變更後需重新核對。
- 預設不自動刪除任何一邊的檔案；大量刪除一律暫停。
- **離線保護**：NAS 根目錄無法存取時整組略過；讀不到的資料夾、因篩選略過的檔案都不會被當成刪除。
- 替換檔案一律「先完成並驗證新版、再處理舊版」。
- 115 刪除進 115 回收站；NAS 被覆蓋或刪除的檔案先移到對應根目錄下的 `.nas115sync_trash\日期時間\`（預設保留 30 天）。

### 資安設計

- **登入資訊**：115 cookies 以 Windows DPAPI 加密（加密失敗就不保存）；cookies 只會送到 `*.115.com`，下載的 CDN 與上傳的阿里雲 OSS 不會收到；
  紀錄檔與畫面紀錄會自動遮蔽任何像 cookie 或憑證的字串。
- **路徑安全**：115 上的名稱若含 `..`、`\`、磁碟代號、`:`（NTFS 隱藏資料流）、Windows 保留名稱（`CON`、`NUL`…）、結尾空白或句點，
  一律略過並在比對結果提出警告；每次寫入 NAS 前再確認實際位置（解析捷徑、符號連結、junction 後）仍在該對應的資料夾內。
- **只連 HTTPS**、驗證憑證；本程式不開啟任何連接埠、不執行下載的檔案。
- 呼叫 Windows 系統程式（`tasklist`、`explorer`）一律用完整路徑，避免同資料夾中被放置的同名程式被執行。
- 匯出的 CSV 會中和以 `= + - @` 開頭的檔名，避免 Excel 把檔名當成公式執行。
- 每次建置都以 bandit（程式碼靜態分析）與 pip-audit（相依套件已知漏洞）檢查。

## 遊戲存檔（Steam 雲存檔式同步）

- 自動偵測：路徑中有 `SaveData`、`Saves`、`SaveGames`、`Saved Games`、`存檔` 等資料夾，
  或副檔名為 `.sav`、`.sl2`、`.ess` 等（可在「設定」修改），即視為一個「存檔群組」。
- 第一次偵測到時列入「待核對」：**核可**（可填遊戲執行檔，例如 `eldenring.exe`）／當一般檔案／不同步。
- 核可後：存檔有變動 → 等存檔靜置（預設 60 秒）且遊戲程序已結束 → 上傳變動的存檔 → **刪除 115 舊版**
  （或移到 `.savedata_versions` 保留 N 份）。
- 對應設為**雙向**時，程式每 2 分鐘檢查 115 上的存檔，別台電腦上傳的新存檔會在遊戲沒有執行時下載回來。
- 兩邊存檔都被改過時不會互相覆蓋，列入待核對。

## 即時同步說明

- 監看 NAS 資料夾的新增、修改、改名、搬移、刪除事件；檔案停止變動（預設 5 秒）後才處理。
- NAS 上改名或搬移已同步的檔案／資料夾，直接在 115 改名或搬移，不需重新上傳。
- **115 端的變動**（下載／雙向模式）：每 30 秒（可在設定修改）讀取 115 的操作紀錄，只重新讀取受影響的資料夾並同步到 NAS；
  115 上改名或搬移已同步的檔案／資料夾，NAS 上直接改名或搬移；115 上刪除依「刪除處理」設定（預設交給本人核對）。
  另有定期完整比對（預設 15 分鐘）作為保險；存檔群組依遊戲存檔規則同步。
- 網路磁碟（SMB）偶爾會漏掉事件，定期完整比對會補上；若 NAS 完全不回報事件，可勾選「改用輪詢監看」。

## 注意事項與限制

- 115 對呼叫頻率有限制（過快可能要求安全驗證），程式預設每次呼叫間隔 0.4 秒並在被要求放慢時自動等待重試；
  若出現「115 要求安全驗證」，請用 115 電腦版或網頁開啟網盤完成驗證後再繼續。
- 第一次比對需要把 NAS 所有檔案完整讀一次以計算 MD5/SHA-1（TB 級資料需要數小時），之後只計算有變動的檔案。
- 排程與即時同步需要本程式在執行中（可勾選開機自動啟動）；也可用 Windows 工作排程器執行 `run_cli.bat sync --yes`。
- 115 介面若有變動，可能需要更新程式（相關程式碼集中在 `nas115sync/cloud/web115.py` 與 `web115_codec.py`）。
